# 1. Аналитика конференций TED: Дашборд для организаторов

## Описание проекта
Дашборд разработан для компании, которая преобрела лицензию на проведение конференций TED. Заказчику требуется инструмент для планирования собственного мероприятия: выбора популярных тем, подбора выступающих, организации хронометража и прогнозирования реакций аудитории.

**Цель:** создать интерактивный дашборд в DataLens, позволяющий исследовать исторические данные конференций TED по ключевым бизнес-метрикам.

**Источник данных:** публичный датасет конференций TED (содержит информацию о выступлениях, просмотрах, реакциях зрителей, тегах и метаданных мероприятий).

---

## Функциональность дашборда

### Блок 1: Общая статистика
- Количество конференций (с учётом мероприятий без выступлений через `LEFT JOIN`);
- Общее число выступлений;
- Уникальное количество выступающих;
- Количество уникальных тегов.

### Блок 2: Анализ конференций
- Фильтры по: **стране**, **названию конференции**, **тегу**, **дате записи**;
- Средняя длительность выступления;
- Максимальное количество просмотров;
- Сумма аплодисментов за конференцию;
- Количество выступающих.

### Блок 3: Исследование выступлений
- **Топ-10** самых смешных выступлений (по реакции аудитории);
- **Топ-20** самых популярных тегов.

### Блок 4: Портрет выступающих
- Определение сфер деятельности (род занятий) выступающих с наибольшим количеством аплодисментов;
- Детальная карточка каждого выступления при клике.

## Этапы работы над проектом

### 1. Исследовательский анализ данных (EDA)
В ноутбуке выполнены:
- Загрузка и первичный осмотр структуры данных (`.info()`, `.head()`, `.describe()`);
- Проверка на пропуски и дубликаты;
- Анализ распределений ключевых метрик (длительность выступлений, просмотры, реакции);
- Преобразование типов данных для корректной работы в DataLens.

### 2. Подготовка витрины для дашборда
- Формирование `flat table` с необходимыми полями;
- Агрегация данных по конференциям и выступлениям;
- Создание вычисляемых полей (средняя длительность, суммарные аплодисменты).

### 3. Разработка дашборда в DataLens
- Построение интерактивных графиков и таблиц;
- Настройка фильтров и селекторов;
- Организация компоновки для удобства пользователя.

### 4. Формулировка инсайтов
- На основе визуализаций сформулированы рекомендации для заказчика.
