# Анализ поведения пользователей книжного приложения: A/B-тестирование

## Цель проекта

Цель данного исследования — провести комплексный анализ поведения пользователей книжного приложения, включая проверку гипотезы о различиях в активности между Москвой и Санкт-Петербургом, а также оценку результатов A/B-теста нового интерфейса.

## Задачи исследования

### Часть 1: Сравнение пользователей из Москвы и Санкт-Петербурга

*   **Проверка гипотезы:** Проверить, проводят ли пользователи из Санкт-Петербурга в среднем больше времени за чтением и прослушиванием книг, чем пользователи из Москвы.
*   **Методология:** Проведение одностороннего t-теста для двух независимых выборок.
*   **Результат:** Статистически значимых различий в активности между пользователями двух городов не обнаружено (p-value = 0.338 > 0.05).

### Часть 2: Анализ A/B-теста

*   **Оценка корректности теста:** Проверка соответствия теста техническому заданию, анализ распределения пользователей по группам и устройствам, выявление пересечений с другими тестами.
*   **Анализ данных:** Расчет лайфтайма пользователей, оценка конверсии в покупку в течение 7 дней после регистрации.
*   **Расчет минимального размера выборки:** Расчет необходимого размера выборки для обнаружения целевого эффекта (+3 процентных пункта) с мощностью 80% и достоверностью 95%.
*   **Статистический анализ:** Проверка статистической значимости различий в конверсии между контрольной и тестовой группами.
*   **Результаты:** Тест показал статистически значимое улучшение конверсии (p-value = 0.028 < 0.05), однако целевой показатель (+3 процентных пункта) не был достигнут.

## Результаты исследования

### Часть 1: Сравнение пользователей

*   **Размер выборки:** 6 234 пользователя из Москвы и 2 306 из Санкт-Петербурга.
*   **Среднее время активности:**
    *   Москва: 10.88 часов.
    *   Санкт-Петербург: 11.26 часов.
*   **Статистическая значимость:** Разница не является статистически значимой (p-value = 0.338). Мы не можем отвергнуть нулевую гипотезу о том, что среднее время активности в двух городах одинаково.
*   **Возможные причины:** Недостаточная мощность теста или наличие выбросов в данных.

### Часть 2: A/B-тестирование

*   **Состояние теста:** Тест `interface_eu_test` был проведен корректно (название, группы, распределение пользователей соответствуют ТЗ).
*   **Проблемы:** Обнаружены пересечения с другими тестами (887 пользователей). Эти пользователи были исключены из анализа, чтобы избежать искажения результатов.
*   **Конверсия:**
    *   Группа A (контрольная): 27.81%
    *   Группа B (тестовая): 29.54%
*   **Статистическая значимость:** Разница в конверсии статистически значима (p-value = 0.028). Новый интерфейс показывает улучшение конверсии на 1.73 процентных пункта.
*   **Целевой показатель:** Требуемое улучшение в 3 процентных пункта не достигнуто.
