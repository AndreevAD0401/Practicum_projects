# Анализ А/В-теста: эксперимент по онбордингу в SollmaFin

## Описание проекта

В проекте проводится анализ А/В-теста, проведённого SollmaFin — международным мобильным приложением для онлайн-торговли финансовыми активами. Продукт ориентирован на начинающих инвесторов из Латинской Америки (Мексика, Бразилия, Колумбия, Аргентина), которые могут пользоваться сервисом как через мобильное приложение, так и через веб-версию.

**Бизнес-гипотеза:** пользователям не хватает финансовой грамотности — они не понимают рисков, связанных с разными типами активов, что приводит к потерям и снижению вовлечённости. Команда продукта предложила обновить онбординг, добавив в него детальную информацию об активах и связанных с ними рисках.

**Основные вопросы:**
- Помогает ли новый онбординг пользователям лучше понимать принципы инвестирования и увеличивает ли частоту повторных депозитов?
- Отпугивает ли информация о рисках осторожных пользователей и снижает ли конверсию в первый депозит?
- Возвращаются ли пользователи, выбравшие высокорискованные активы, чаще после нового онбординга?

---

## Дизайн эксперимента

**Период:** пользователи регистрировались со 2 по 15 июня 2025 года, активность анализировалась в течение недели.

**Группы:**
- **Контрольная группа (n=4 847):** стандартный онбординг без обязательного обучения
- **Тестовая группа (n=4 568):** обновлённый онбординг с подробной информацией об активах и рисках

**Метрики:**
- **Ключевая метрика:** средняя сумма всех депозитов на одного пользователя (включая неплатящих)
- **Барьерная метрика:** конверсия из регистрации в первый депозит
- **Вспомогательная метрика 1:** конверсия из первого депозита во второй
- **Вспомогательная метрика 2:** средняя сумма всех депозитов на платящего пользователя

---

## Источники данных

Используются два набора данных:

1. **Исторические данные:** действия пользователей, привлечённых с 1 апреля по 1 июня 2025 года
2. **Данные А/В-теста:** действия пользователей, зарегистрировавшихся со 2 по 15 июня 2025 года

**Основные поля:**
- `user_id` — уникальный идентификатор пользователя
- `country_code` — код страны (BR, MX, AR, CO)
- `platform` — устройство: mobile или web
- `first_ts` / `first_dt` — время и дата первого появления пользователя
- `event_ts` — время события
- `event_name` — название события
- `amount` — сумма пополнения депозита
- `asset` — тип приобретённого актива
- `risk_level` — уровень риска актива (low/medium/high)

**Дополнительные поля для А/В-теста:**
- `ab_test` — название эксперимента
- `group` — группа пользователя (control или test)

## Этапы анализа

### 1. Анализ исторических данных
- Динамика привлечения новых пользователей
- Воронки событий (классическая и пошаговая)
- Влияние уровня риска первого актива на конверсию во второй депозит
- Базовый уровень монетизации (ключевая метрика)

### 2. Анализ результатов А/В-теста
- Проверка корректности распределения пользователей по группам
- Сравнение воронок событий в группах
- Анализ влияния уровня риска на конверсию во второй депозит с учётом группы
- Статистическая проверка метрик (t-test, z-test для пропорций)

### 3. Бутстрап-анализ
- Сравнение перцентилей (25, 50, 75) суммы депозитов на платящего пользователя
- Построение доверительных интервалов для разницы между группами

---

## Ключевые результаты

### 1. Гипотеза риска — НЕ ПОДТВЕРДИЛАСЬ
- Конверсия в первый депозит снизилась незначительно (71,5% → 70,0%)
- Разница **статистически незначима** (p-value > 0,05)
- Новый онбординг не отпугнул пользователей от первого вложения

### 2. Гипотеза роста — ПОДТВЕРДИЛАСЬ ✓
- Конверсия во второй депозит **выросла на 58%** (13,49% → 21,32%)
- Разница **статистически значима** (p-value < 0,05)
- Пользователи, прошедшие обучение, с большей вероятностью возвращаются

### 3. Дополнительная гипотеза — ПОДТВЕРДИЛАСЬ ✓
- Наибольший рост конверсии во второй депозит наблюдается в сегменте **высокорискованных активов** (+18,3 п.п.)
- p-value < 0,05 — разница статистически значима

### 4. Платящие пользователи стали вкладывать больше
- Средняя сумма депозита на платящего пользователя выросла на **4,4%** (135,50 → 141,40)
- Разница **статистически значима** (p-value = 0,040)

### 5. Изменение распределения депозитов
- **25-й перцентиль:** значительно снизился (95 → 48) — осторожные пользователи сократили вложения
- **50-й перцентиль:** значительно снизился (118 → 94) — медианный пользователь стал вкладывать меньше
- **75-й перцентиль:** вырос (159 → 179,5) — уверенные инвесторы увеличили вложения
